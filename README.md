# 성남 아동수당·상품권 쓸 수 있는 가게

가게 이름만 넣으면 그 가게에서 **아동수당 포인트**와 **성남사랑상품권** 중
무엇을 쓸 수 있는지 알려주는 정적 웹앱입니다.

두 제도의 공식 조회 화면은 서로 다른 사이트에 흩어져 있고, 신한카드 쪽은
`지역 → 업종 → 가게 이름`을 모두 고른 뒤에야 검색이 되며 지도도 없습니다.
이 앱은 양쪽 가맹점을 모두 모아 하나로 합치고, 이름 하나로 바로 찾게 만듭니다.

## 쓰는 법

- 가게 이름을 입력하면 즉시 결과가 좁혀집니다. **초성 검색**도 됩니다 (`ㅍㄹㅂㄱㄸ` → 파리바게뜨).
- **자치구**(수정·중원·분당) 또는 **역 주변**으로 위치를 고릅니다.
  역 주변은 성남시 지하철역 20곳에서 300m / 500m / 1km 반경으로 찾고,
  결과는 가까운 순으로 정렬되며 각 줄에 역까지 거리가 붙습니다.
- 업종은 8개 그룹(먹거리·장보기·의료·교육·미용·패션·여가·생활)으로 나뉘고,
  그룹을 고르면 **세부 업종**이 펼쳐집니다 (먹거리 → 한식 / 카페·제과 …, 의료 → 병원 / 약국 …).
- 목록의 핀 버튼을 누르면 지도에서 해당 위치로 이동합니다.
- 전화번호가 있는 가게는 바로 전화를 걸 수 있습니다.

지하철역 좌표는 [OpenStreetMap](https://www.openstreetmap.org)에서 받아
노선별 노드를 평균낸 값이며 `app.js`의 `STATIONS`에 들어 있습니다.

## 지도 (카카오맵)

앱키가 `app.js`의 `KAKAO_KEY`에 들어 있어 그냥 열면 바로 지도가 뜹니다.

카카오 JavaScript 키는 브라우저 소스에 노출될 수밖에 없는 값이고,
등록된 도메인에서만 동작하므로 다른 사이트로 옮겨 써도 소용이 없습니다.

키를 새로 발급하거나 다른 도메인에 올릴 때는 [카카오 개발자센터](https://developers.kakao.com/console/app)에서:

1. **앱 → 플랫폼 키 → JavaScript SDK 도메인**에 주소를 등록합니다.
   경로 없이 도메인까지만 넣습니다 (`https://pjungjin85-sketch.github.io`).
2. **제품 설정 → 카카오맵 → 활성화 설정**을 **ON**으로 바꿉니다.
   이걸 켜지 않으면 `disabled OPEN_MAP_AND_LOCAL service` 오류가 납니다.
3. 같은 화면의 JavaScript 키를 `app.js`의 `KAKAO_KEY`에 넣습니다.

앱의 `지도` 탭에서 키를 직접 입력하면 `localStorage`에 저장되어 기본 키를 덮어씁니다.
`?key=발급받은키`로 주소에 붙여 열어도 됩니다.

**목록·검색은 지도와 무관하게 동작합니다.**

## 데이터

| 항목 | 아동수당 포인트 | 성남사랑상품권 |
| --- | --- | --- |
| 출처 | 신한카드 가맹점 조회 (`crawl.py`) | 성남시 가맹점 통합검색 엑셀 (`crawl_gift.py`) |
| 건수 | 33,758 | 24,078 |
| 좌표 | 응답에 포함 (TM 중부원점 `EPSG:5174` → `EPSG:4326`) | **없음** — 주소로 채움 |
| 업종 | 183종 (세분) | 7종 (품목 단위, 거침) |

두 자료를 `상호+구+도로명주소` → `전화번호` → `상호+구` 순으로 대조해 합칩니다.
상품권 가맹점의 74%가 아동수당 가맹점과 연결되고, 나머지는 새 항목으로 추가합니다.
상품권 자료에는 좌표가 없어 같은 주소에 있는 다른 가맹점의 좌표를 빌려 씁니다(92% 확보).

지오코딩 API는 쓰지 않습니다. 아동수당 자료의 좌표계는 현대백화점 판교점 등
실좌표와 대조해 확인했습니다 (오차 약 50m, `EPSG:5181`·`EPSG:2097`로 해석하면 250~300m 벗어납니다).

**합칠 때 감안해야 할 것**

- 대조가 완벽하지 않습니다. 상호나 주소 표기가 달라 같은 가게가 두 줄로 남을 수 있고,
  반대로 이름이 같고 한 곳뿐인 가게는 실제로 다른 곳인데 합쳐졌을 수 있습니다.
- 상품권 자료의 업종은 7종뿐이라, 상품권에만 있는 가맹점은 세부 업종이 '기타'로 들어갑니다.
- 배지는 **공식 가맹점 목록에 올라 있다**는 뜻이지, 결제가 된다는 보장이 아닙니다.
  신한카드도 같은 안내를 하고 있습니다 — *"아동수당가맹점으로 검색이 되더라도 다수의
  가맹점을 운영하거나 사업자 변경이 된 경우 등 포인트 사용이 불가능한 가맹점일 수 있으니
  이용 전 확인하시기 바랍니다"*, *"가맹점에서 운영하는 단말기 카드승인 방식(결제대행 등)에
  따라 포인트 사용이 불가할 수 있습니다"*. 앱 상세 화면에도 이 경고를 띄웁니다.

## 데이터 갱신

```bash
pip install pyproj openpyxl
python3 crawl.py          # 아동수당  -> data/raw_merchants.json  (약 2분)
python3 crawl_gift.py     # 상품권    -> data/gift_merchants.xlsx (수초)
python3 build_dataset.py  # 대조·가공 -> merchants.json
```

`crawl.py`는 `MCT_N` 구간을 나눠 병렬로 수집하고 20초마다 중간 결과를 저장합니다.
`build_dataset.py`는 좌표를 변환하고, 두 자료를 대조해 결제수단을 합치고,
업종을 8개 그룹 아래 세부 업종으로 분류합니다.

## 배포

GitHub Pages용 정적 파일입니다. 저장소 루트를 그대로 배포하면 됩니다.

```

```

## 알아두실 점

가맹점은 수시로 바뀝니다. 이 목록은 수집 시점 기준이며, 결제 전 가게에 확인하는 편이 안전합니다.

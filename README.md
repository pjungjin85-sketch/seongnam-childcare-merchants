# 성남시 아동수당 쓸 수 있는 가게

성남시 아동수당 포인트 가맹점을 **이름만으로 한 번에 검색**하고 **지도에서 위치를 확인**하는 정적 웹앱입니다.

신한카드 공식 조회 화면은 `지역 → 업종 → 가게 이름`을 모두 고른 뒤에야 검색할 수 있습니다.
업종을 모르면 찾을 수 없고, 지도도 없습니다. 이 앱은 전체 가맹점을 미리 모아두고
이름 하나로 바로 찾게 만듭니다.

## 쓰는 법

- 가게 이름을 입력하면 즉시 결과가 좁혀집니다. **초성 검색**도 됩니다 (`ㅅㅌㅂㅅ` → 스타벅스).
- 구(수정·중원·분당)와 업종 그룹으로 추가로 거를 수 있습니다.
- 목록의 핀 버튼을 누르면 지도에서 해당 위치로 이동합니다.
- 전화번호가 있는 가게는 바로 전화를 걸 수 있습니다.

## 지도 켜기 (카카오 앱키)

지도는 카카오맵을 씁니다. 무료지만 앱키가 필요합니다.

1. [카카오 개발자센터](https://developers.kakao.com/console/app)에서 애플리케이션을 만듭니다.
2. **앱 설정 > 플랫폼 > Web**에 사이트 주소를 등록합니다.
   - 배포 주소: `https://<사용자>.github.io`
   - 로컬 확인용: `http://localhost:8000`
3. **앱 키 > JavaScript 키**를 복사합니다.
4. 앱의 `지도` 탭에서 키를 붙여넣고 **지도 켜기**를 누릅니다.

키는 브라우저 `localStorage`에만 저장되고 저장소에 커밋되지 않습니다.
`?key=발급받은키` 형태로 주소에 붙여 열 수도 있습니다.

**목록 검색은 키가 없어도 그대로 동작합니다.**

## 데이터

| 항목 | 내용 |
| --- | --- |
| 출처 | 신한카드 `성남시 아동수당 포인트 가맹점 찾기` 조회 화면 |
| 수집 항목 | 가맹점명, 주소, 업종, 전화번호, 좌표 |
| 좌표계 | 원본은 TM 중부원점(Bessel, `EPSG:5174`) → `EPSG:4326`으로 변환 |

좌표는 응답에 이미 들어 있어 별도 지오코딩 API를 쓰지 않습니다.
좌표계는 현대백화점 판교점 등 실좌표와 대조해 확인했습니다 (오차 약 50m,
`EPSG:5181`·`EPSG:2097`로 해석하면 250~300m 벗어납니다).

주소는 가맹점마다 정밀도가 다릅니다. 최근 갱신된 곳은 도로명 전체 주소가,
오래된 곳은 동까지만 들어 있습니다. 다만 **좌표는 모두 지점 단위**라 지도 위 핀은 정확합니다.

## 데이터 갱신

```bash
pip install pyproj
python3 crawl.py          # 전체 수집 -> data/raw_merchants.json
python3 build_dataset.py  # 가공 -> merchants.json
```

`crawl.py`는 `MCT_N` 구간을 나눠 병렬로 수집하고 20초마다 중간 결과를 저장합니다.
`build_dataset.py`는 좌표를 변환하고, 세부 업종명을 8개 그룹(먹거리·장보기·의료·교육·미용·패션·여가·생활)으로
분류하고, 초성 검색 인덱스를 만듭니다.

## 배포

GitHub Pages용 정적 파일입니다. 저장소 루트를 그대로 배포하면 됩니다.

```
index.html  style.css  app.js  merchants.json
```

## 알아두실 점

가맹점은 수시로 바뀝니다. 이 목록은 수집 시점 기준이며, 결제 전 가게에 확인하는 편이 안전합니다.

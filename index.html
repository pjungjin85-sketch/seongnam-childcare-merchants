    찾는 가게가 없습니다. 가게 이름 일부만 넣거나, 결제수단·지역·업종 필터를 풀어 보세요.

    지도를 켜려면 카카오 앱키가 필요합니다

    1. 카카오 개발자센터에서 앱을 만듭니다.
    2. 앱 > 플랫폼 키 > JavaScript SDK 도메인에 이 주소를 등록합니다.
      —
    3. 제품 설정 > 카카오맵의 활성화 설정을 ON으로 바꿉니다.
    4. 같은 화면의 JavaScript 키를 복사해 아래에 붙여넣습니다.

    키는 이 브라우저에만 저장됩니다. 목록 검색은 키 없이도 그대로 됩니다.

    자료 출처 — 아동수당은 신한카드 성남시 아동수당 포인트 가맹점 찾기, 상품권은 성남시 성남사랑상품권 가맹점 통합검색. 배지는 공식 가맹점 목록에 올라 있다는 뜻입니다. 목록에 있어도 가게 단말기 방식이나 사업자 변경 때문에 결제가 안 될 수 있으니, 계산 전에 물어보세요.
